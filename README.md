## 구성

| 갈래 | 위치 | 내용 |
|---|---|---|
| Portfolio | `/` · `app/data/portfolio.ts` | 포트폴리오 · 프로젝트 상세 |
| Blog | `/blog` | 블로그 입구 |
| Post | `src/content/posts` | 기술 글 |
| Study | `src/content/study` | 개인 공부 기록 |
| Work | `src/content/work` | 실무 학습 기록 |
| Diary | `src/content/diary` | 일기 |

- React Router 7(Vite)로 전 주소를 정적 HTML 로 빌드 / main에 푸시하면 GitHub Actions로 GitHub Pages에 배포

## 로컬 실행

```sh
npm install
npm run dev
```
